Temporary

Two ways to make the Knowledge Bank work offline on an iPhone: Add to Home Screen (recommended) or an exported folder.

The Knowledge Bank is a static website (HTML, CSS, JavaScript, images) with relative links between pages. A copy of the published files works without internet in any app that can display a local web folder. Click a box to open it.

What the Knowledge Bank Is

TypeStatic website
Built from
Plain HTML, CSS, JavaScript, and images, with relative links between files — no database, no server-side code
Offline potential
A copy of the published files works without internet in any app that can display a local web folder
Ways to get there
Two options: Add to Home Screen in Safari (recommended), or an exported folder copied to the phone

Option 1: Add to Home Screen (Recommended)

NeedsWeb app manifest + service worker
Setup
Add two small files to the site: a web app manifest and an offline cache script (a service worker)
On the iPhone
  • Open the live site once in Safari.
  • Choose Share > Add to Home Screen.
  • A KB icon appears and opens the site full screen, like an app.
Offline use
After the first visit, every page and image is stored on the phone and works offline, for example in airplane mode
Updates
Automatic: whenever the phone is online, it picks up whatever has been published
Trade-off
Relies on the public GitHub site for the first load and for updates — the site is already public, so nothing new is exposed

Option 2: Exported Folder

NeedsExport tool + third-party viewer app
Setup
Add an export tool (for example a VS Code task or a button) that builds a clean folder, plus a .zip, with only what the site needs: index.html, html_pages/, kb_images/, assets/, kb_config.js; the private data/ folder, logs, tools, and tests are left out
Getting it to the phone
Copy it through OneDrive or iCloud Drive, then open index.html in a viewer app
Catch
The iPhone's built-in Files app and Safari don't browse a local multi-page website well — links between pages and the expand buttons usually fail there, so a third-party app that can open a folder of HTML files with its links and scripts (such as a code editor with a preview) would be needed; which current apps handle this properly should be confirmed before recommending one
Updates
Manual: the folder has to be exported and copied again each time
